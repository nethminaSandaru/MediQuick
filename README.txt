MEDIQUICK PHARMACY - PHP/MySQL STUDENT PROJECT
===============================================
Technology: PHP, HTML5, CSS3, JavaScript, MySQL/phpMyAdmin.

INSTALLATION
1. Install XAMPP.
2. Copy the MediQuick_Pharmacy folder to C:\xampp\htdocs\
3. Start Apache and MySQL in XAMPP.
4. Open http://localhost/phpmyadmin
5. Import database.sql.
6. Open http://localhost/MediQuick_Pharmacy/



IMPORTANT
This is an academic/demo application. Payment is simulated and no real card data is collected.
For a production system, use a real payment provider, HTTPS, secure file storage, CSRF protection, rate limiting, audit logs and professional pharmacy/legal compliance.

USER APPROVAL RULE
New customer accounts are created with status=1 (pending).
Admin approves an account by changing status to 0. Only status=0 can log in.

MAIN FEATURES
- Responsive pharmacy storefront
- Search/filter products
- Product details, dosage and safety information
- Registration/login with strong password validation
- Admin account approval
- Cart and checkout
- Demo payment methods
- Prescription upload and admin verification
- Order tracking and admin status management
- Customer profile
- Contact/inquiries
- Admin product inventory management
